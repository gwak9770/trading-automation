- 검증된 근거: g2의 Ubuntu20.04와 g3/g3a의 Ubuntu22.04/24.04 호환성, 기본 디스크 최소50/10GB, 기존 리소스0개. Ubuntu20.04 표준 지원 종료를 고려해 Ubuntu24.04의 g3/g3a를 후보로 제안하지만 실제 선택·성능 검증은 아닙니다.
- 대안: g2 HDD/SSD50GB는 20.04 지원 조건 확인이 필요합니다. g3/g3a의 최소10GB는 초기 비교용이며 같은50GB 비용도 별도로 계산합니다. g3a 단가 미확인 상태에서 g3와 같거나 더 저렴하다고 가정하지 않습니다.
- 미결정: 세대·CPU·디스크 용량·작업량·운영 시간, 외부 AI 비용·실행 구조, 정지 누적 제한 해석, g3a 가격과 크레딧 적용 조건. 서버 생성·운영은 별도 명시적 요청과 검증이 필요합니다.
