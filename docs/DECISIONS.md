# 의사결정 기록

## 2026-11-10 — 분석과 주문 실행 분리 (계획)

유튜브 전략 분석과 Binance Futures 주문 실행을 별도 컴포넌트로 구성할 계획입니다. 시스템 아키텍처는 구상 중이며 실제 구현은 확인되지 않았습니다.

## 2026-11-10 — 개발 환경 및 배치 (계획)

개인 Windows 데스크톱에서 시작해 현재 Windows 노트북의 Codex CLI를 활용합니다. Python 분석 프로그램은 개발 계획입니다. 각 컴포넌트 src/와 공통 tests/에 코드를 배치합니다. 런타임 버전과 도구는 미정이며 설정·외부 API 접근·비즈니스 로직은 분리합니다.

## 2026-11-10 — 전략 출력 형식 (계획)

Markdown과 JSON 출력을 계획합니다. 구체적 스키마와 검증 방법은 미정입니다. 영상에서 확인한 사실과 AI의 추정·누락 정보를 구분합니다.

## 2026-11-10 — 실거래 활성화 조건 (구현 시 적용)

실거래는 기본 비활성화합니다. mock·fixture·sandbox로 검증하고 백테스트·모의매매·위험 한도·복구 절차 검증 후 명시적 설정을 요구합니다. 실제 주문 프로그램은 아직 없습니다.

## 2026-11-10 — 공개 개발 준비와 검증 경계

- 결정: 기존 커밋을 보존하고 문서·제외 규칙을 보완한 뒤 승인받아 일반 Commit·Push합니다. Visibility는 별도 작업으로 둡니다.
- 이유: 기존 검토 근거와 개발 과정을 유지하면서 공개 범위 변경을 사용자가 통제하기 위함입니다. 이력 재작성·저장소 재생성은 사용하지 않습니다.
- 결정: 로컬 DB와 백업은 제외하되 SQL 소스는 제외하지 않습니다. DB fixture는 tests/fixtures/, 공개 예시는 data/examples/ 아래에서 허용합니다. 이 디렉터리는 필요할 때 생성합니다.
- 이유: 인증정보·실제 거래 데이터 유입을 줄이면서 재현 가능한 테스트·예시를 공유하기 위함입니다. 모든 DB·SQL 자료를 일괄 배제하는 대신 경로와 내용 검사를 병행합니다. 예외 경로에도 실제 자격증명·개인정보를 넣지 않습니다.
- AI 범위: ChatGPT는 요구사항·설계 검토를, Codex CLI는 파일 수정·명령 실행·검증을 지원합니다. 현재 결과는 문서·공개 준비에 한정하며 사용자 확인, 도구 검증과 AI 제안을 구분합니다.

## 남은 설계 결정

Python 버전, 의존성, AI 서비스, 데이터 저장 방식, 전략 스키마와 서버 운영 구성은 추가 설계가 필요합니다. 실제 서버는 아직 생성되지 않았습니다.
