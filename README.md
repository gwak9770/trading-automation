# Trading Automation

유튜브에 소개된 매매 전략을 구조화하고 검증한 뒤, 향후 Binance Futures 자동매매 연구로 연결하기 위한 공개 개발 준비 프로젝트입니다. 현재는 문서·설계 준비 단계이며 분석 프로그램, 주문 기능과 성과 측정 결과는 없습니다.

## 주요 구성 요소

| 경로 | 목적 및 현재 상태 |
| --- | --- |
| `youtube-analyzer/` | 영상 목록·자막 수집, AI 전략 추출과 Markdown·JSON 출력 계획 |
| `trading-bot/` | 분석과 분리된 주문 실행 컴포넌트 계획, 미구현 |
| `strategies/` | 향후 전략 문서·구조화 결과 저장 위치 |
| `tests/` | 향후 결정적 테스트·fixture 위치, 테스트 코드 없음 |
| `infrastructure/` | 네이버 클라우드 구축 계획, 서버 생성·운영 미검증 |
| `docs/` | 로드맵과 설계 결정 기록 |

## 사용 기술 및 개발 환경

- 현재: Windows 노트북, Git, GitHub CLI, Codex CLI, Markdown. 노트북 설치·인증·Clone·CLI 실행은 사용자 확인, main 동기화는 도구로 확인했습니다.
- 계획: Python 기반 분석, YouTube 데이터·자막 처리, AI 전략 추출, Binance Futures 연계, 네이버 클라우드 배치. 구체적 라이브러리와 아키텍처는 미확정입니다.
- Python 프로젝트 런타임 버전·의존성·설치·실행·린트·테스트 명령은 아직 설정하지 않았습니다. 구현 시 실제 검증한 명령과 지원 버전을 기록합니다.

## 현재 개발 단계와 향후 계획

GitHub 초기 구축과 노트북 작업 환경 구성은 완료했습니다. 저장소는 현재 Private이며 공개 개발을 위한 문서·제외 규칙을 보완 중입니다. 네이버 클라우드 서버의 실제 생성·접속·운영은 미검증이고, 유튜브 분석·자동매매·백테스트·모의매매·위험 관리 기능은 미구현입니다.

다음 작업은 클라우드 상품·비용·접속 조건 확인, 분석 아키텍처와 Python 개발 도구 선정, 자막 수집 및 전략 추출 구현과 fixture 테스트입니다. 이후 백테스트, 모의매매, 위험 한도와 복구 검증을 진행합니다. 상세 내용은 [프로젝트 상태](PROJECT_STATUS.md), [다음 단계](NEXT_STEPS.md), [로드맵](docs/ROADMAP.md)에 기록합니다.

## AI 활용 개발 방식

ChatGPT는 요구사항 정리·설계 검토·개발 계획 수립을 지원하고, Codex CLI는 저장소 파일 수정·명령 실행·검증을 지원합니다. 현재 AI 활용 결과물은 문서 정비와 공개 준비 작업이며, 프로그램 구현이나 매매 성능 검증을 의미하지 않습니다. 사용자 확인 사실, 도구 검증 결과와 AI 제안을 구분하고 최종 판단은 사용자가 검토합니다. 설계 이유와 미결정 사항은 [의사결정 기록](docs/DECISIONS.md), 작업 기준은 [AGENTS.md](AGENTS.md)를 따릅니다.

## 보안 및 면책

API 키·비밀번호·인증 토큰·SSH 개인키·계정 식별 정보는 커밋하지 않습니다. 실거래 자격증명은 저장소 밖에서 관리하고 주문 기능은 분석과 분리하며, 구현 시 실거래는 기본 비활성화합니다. 백테스트·모의매매·위험 한도·복구 검증과 명시적 설정이 필요합니다.

외부 영상·자막·코드는 출처와 라이선스·재배포 권한을 확인한 범위에서만 추가합니다. 현재 저장소에 해당 원본 자료는 없습니다. 이 프로젝트는 학습·연구 목적이며 투자 조언이나 수익 보장을 제공하지 않습니다. 자동매매에는 원금 손실 위험이 있습니다.
