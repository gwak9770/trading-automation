# 네이버 클라우드 구축 계획

상태: **서버 미생성**. 실제 프로비저닝, SSH 접속과 운영을 확인하지 않았습니다.

## 사용자 제공 정보와 계획

- 개인 계정에 10만 원 크레딧 보유, 유효기간 3개월. 시작일·만료일과 적용 조건은 미확인입니다.
- 영상 분석용 High CPU-g2 서버 구축 예정입니다.
- 자동매매용 무료 Micro-g3 서버 구축 예정입니다.

위 항목은 사용자 제공 정보와 계획입니다. 현재 상품 제공 여부·무료 조건·크레딧 적용 범위·사양·비용은 구축 전에 확인해야 합니다.

## 생성 및 검증 체크리스트

- 크레딧 잔액·정확한 만료일·적용 조건 및 예상 비용 확인
- 리전·운영체제·네트워크·CPU·메모리·디스크 요구사항 결정
- 서버 생성 후 실제 상태와 접속 경로 확인
- SSH 개인키와 계정 정보는 저장소 외부에서 안전하게 관리
- 접근 제어·최소 권한·업데이트·모니터링·복구 검증
- 재시작과 장애 복구 후 서비스 동작 확인

## 운영 기록 원칙

실제 생성·접속 증거를 확보한 뒤에만 완료로 기록합니다. 서버 생성 자체가 24시간 운영 검증을 뜻하지 않습니다. 실제 IP, 계정 식별 정보, SSH 키와 API 자격증명을 저장소에 기록하지 않습니다.
